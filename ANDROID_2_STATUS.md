# JARVIS Android 2.0 – rakennustyö

Android-sovelluksen uusi lähdekoodiprojekti luotu erillisenä pakettina. Lataa tämän keskustelun artefakti **JARVIS_Android_2_lahdekoodi.zip** ja avaa Android Studiossa.

Tämä haara on erillään JARVIS GitHub Pages -julkaisusta. Lähdekoodin täydellinen siirtäminen haaralle on vielä tekemättä; tämä merkintä ei tarkoita, että APK olisi rakennettu tai testattu.

Ensimmäisen version toiminnot: natiivi Androidin puheentunnistus, paikallinen hologrammianimaatio, verkkosisällön päivittäminen selaimeen ja linkki APK-päivityksiin. Taustalla herätesanan kuuntelu, Adam-ääni ja aito AR-hahmo eivät kuulu tähän ensimmäiseen versioon.

Käyttöön tarvitaan Android Studio + SDK ja sovelluksen kääntäminen, jota ei tässä ympäristössä vielä ole tehty.
